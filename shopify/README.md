# Shopify Build Pack

This folder is a Shopify-ready starter content pack for launching the premium golf essentials brand from the blueprint.

## What to import/build first

1. Import `shopify/data/products.csv` into Shopify Products.
2. Create collections listed in `shopify/data/collections.csv`.
3. Build menus from `shopify/data/navigation.json`.
4. Paste page copy from files in `shopify/pages/`.
5. Use `shopify/theme_blueprint.md` to assemble homepage and product page sections.

## Hero product setup

- Hero bundle product: **The Weekend Golf Kit**
- Lead component + standalone product: **The Roo Pouch**
- Positioning line: **Premium golf essentials for the round before the round.**
